# Engine compatibility: architecture

Nothing moves. The crate re-exports liveupdate's vocabulary of a notification, so a presentation's new member
and the capability arrive with the dependency. What the crate adds sits where its neighbours are:

- `layout.rs`: `AndroidOptions.wear_ongoing_activity` beside the public version and the placement; the strict
  reader of a layout request knows the one member of a presentation that is `true` by default.
- `android/layouts.rs`: the start's option goes into every snapshot that is posted, where the public version of
  the start already goes; the options are compared with a default written out as the default.
- `event.rs`, `android/mod.rs`, `android/layouts.rs`: `Event::Unknown`, from both places that take liveupdate's
  events, with the key where the layouts' store knows the activity.
- `models.rs`, `image.rs`: the constructors and the attribute of the two enums.
